# Warium: Machine Uprising

An unofficial addon for Minecraft Java Edition 1.20.1 (Forge 47+) that makes Warium machines hunt players through rare roaming robots, periodic air raids, and large invasion waves. It also increases the placement frequency of selected Warium structures in newly generated chunks.

## Requirements
- Minecraft 1.20.1
- Minecraft Forge 47+
- Warium (`crusty_chunks`) 1.3.5+
- Java 17 to build

## Build
Run `gradle build` from the project root (or `./gradlew build` if the Gradle wrapper is present). The output JAR is written to `build/libs/`.
